# datahelix-platform.github.io

Root site for the datahelix-platform organization. It only redirects to the
DataHelix documentation at https://datahelix-platform.github.io/datahelix/,
which is built from the [datahelix](https://github.com/datahelix-platform/datahelix)
repository. Component documentation lives at each repository's own Pages site.

`404.html` is the same redirect, so unknown paths under the root land on the
documentation too. Project sites such as `/mosaic` take precedence over it.
